🧭 Inside the studio

One workspace. Every part of the pack.

Explore screenshots from the actual Modspire app and see how the tools fit together.

🤖 Start with a world idea

Describe the atmosphere or name a specific mod. The Pack Assistant uses your active Minecraft setup and current selection to shape catalog suggestions.

🔎 Search the catalog

Browse Modrinth directly, filter for your game version and loader, and add or remove mods from the result cards.

🧪 Review the pack

Use Pack Lab tools for dependency notes, compatibility context, snapshots, crash-log review, and pack diagnostics.

🎨 Shape your workspace

Choose among four layouts, several visual themes, Minecraft-inspired wallpapers, and motion controls.

✨ What Modspire can do

From first idea to a pack you can share.

Keep the decisions in your hands while the studio organizes the research and project details.

💬 Pack Assistant

Continue a themed or exact-name search in chat with context from the selected pack.

🧭 Mod selection

Use direct catalog search, filters, suggestion sorting, and a pack tray to manage candidates.

🧪 Pack Lab

Review project snapshots, category balance, mod roles, dependencies, and diagnostics.

🛠️ Mod Creator

Turn a mod concept into a structured specification and starter-code outline.

📦 Project tools

Keep multiple packs, import Modrinth links or .mrpack files, and export your project.

🌐 Local web view

Open the same local workspace in a browser while the desktop app remains running.

🪄 A simple flow

Choose the direction. Curate the details.

AI can help discover candidates; the catalog and your pack controls keep the workflow reviewable.

01 / DESCRIBE

Set the mood

Give the Pack Assistant a theme, goal, or exact mod name.

02 / DISCOVER

Explore candidates

Search the catalog with your Minecraft version and loader.

03 / CURATE

Build your pack

Add, remove, compare, and review dependencies and notes.

04 / EXPORT

Save the plan

Keep the project locally or export a compatible pack when available.

ℹ️ Project status: Modspire is an independent community test project. Original app files are MIT licensed, while the bundled Sign in with ChatGPT DevKit has separate noncommercial terms, so the combined repository is source-available under multiple licences. Modspire organizes pack plans; it does not install every mod or confirm that Minecraft launches.
🔒 Model compatibility: The app has not been tested with every local model or cloud agent. Check the connected provider’s privacy and usage terms, review suggestions, and test your pack in Minecraft.
