# Modspire Wiki

This folder is the repository's versioned wiki. Pages describe the behavior of the checked-in app; they do not promise that external services, models, or Minecraft mods remain available or compatible.

## Pages

- [Getting started](getting-started.md): install, create a pack, choose a provider, and save/export.
- [Mod search and pack selection](mod-search.md): standard search, AI-assisted suggestions, filters, deduplication, and sorting.
- [Interfaces and designs](interfaces-and-designs.md): four UI layouts, wallpapers, glass surfaces, opacity, and motion.
- [AI, privacy, and limitations](ai-privacy.md): provider behavior, data flow, account/API options, and model compatibility.
- [Troubleshooting and development](troubleshooting-development.md): common problems, tests, and local builds.
- [Licensing and third-party notices](../../THIRD-PARTY-NOTICES.md): the app MIT licence and separate bundled-component terms.

## Scope

Modspire is an independent Minecraft modpack planning tool. It searches catalogs and organizes pack projects; it does not download/install every mod, install a Minecraft loader, or prove a pack works in a launched game. See the root [README](../../README.md) and [public test disclaimer](../../PUBLIC-TEST-DISCLAIMER.md).
